# How To Open PharmaWatch — Simple Step-by-Step Guide
### (No computer experience needed — anyone can do this!)

---

## What Is This?

PharmaWatch is a **website** that shows drug safety information. It looks like a government health website and shows charts, alerts, and data about medicines that might cause side-effects.

You do NOT need to install anything complicated. You do NOT need the internet. You do NOT need to know coding.

---

## The Easiest Way — Just Double-Click!

### Step 1 — Find the folder

Open "File Explorer" on your computer.  
(Press the yellow folder icon on your taskbar, or press the Windows key + E)

### Step 2 — Go to the right place

Navigate to this location:
```
Desktop → PharmaWatch → src
```

You should see three files inside the "src" folder:
- 📄 `index.html`
- 📄 `style.css`
- 📄 `app.js`

### Step 3 — Open the website

**Double-click** the file called `index.html`

That's it! The website will open in your web browser (like Chrome, Edge, or Firefox).

---

## What You Will See

When the website opens, you will see:

1. **A blue header** at the top that says "PharmaWatch"
2. **A navigation bar** with sections you can click on
3. **A dashboard** showing numbers and charts about drug safety

---

## How To Use It

### ▶ Moving Between Pages

At the top, there is a dark blue menu bar. Click any of these words to switch pages:
- **Dashboard** — the main home page with statistics
- **Signal Detection** — a table of dangerous drug signals
- **Drug Search** — search for any medicine
- **Interactions** — see which drugs are dangerous together
- **Data Sources** — see where the data comes from
- **Methodology** — learn how the system works
- **About** — information about the project and the students who made it

### ▶ Searching for a Drug

1. Click "Drug Search" in the top menu
2. Click the search box
3. Type a medicine name (for example: `Metformin`)
4. A suggestion will appear — click on it
5. The page will show charts and safety information about that medicine

You can also click the coloured buttons (Metformin, Atorvastatin, etc.) to search instantly.

### ▶ Seeing Drug Signals

1. Click "Signal Detection" in the top menu
2. A table appears with medicine names and safety scores
3. You can type in the search box to filter the list
4. **Click any row** in the table to see more details about that signal

### ▶ Using the PRR Calculator

1. Click "Methodology" in the top menu
2. Scroll down to the section called "PRR Disproportionality Analysis"
3. You will see boxes labelled a, b, c, d
4. Type numbers in each box
5. Click the blue "Calculate PRR" button
6. The result will appear below, telling you if the signal is LOW, MODERATE, HIGH, or CRITICAL

### ▶ Drug Interaction Graph

1. Click "Interactions" in the top menu
2. Use the dropdown (the box with a list of medicines) to pick a drug
3. Click "Load Graph"
4. An animated diagram will appear showing which medicines are dangerous together
5. Red dots = Critical danger. Orange = Moderate. Green = Safe.

## If the Website Does Not Open

**Problem:** Nothing happens when I double-click `index.html`  
**Solution:** Right-click the file → click "Open with" → choose "Google Chrome" or "Microsoft Edge"

---

**Problem:** The page looks broken or has no colours  
**Solution:** You need an internet connection for the fonts and charts to load. Connect to Wi-Fi and refresh the page (press F5)

---

**Problem:** I cannot find the "src" folder  
**Solution:** Look for the "PharmaWatch" folder on your Desktop. Open it. Inside you should see a folder named "src". Open that folder.
