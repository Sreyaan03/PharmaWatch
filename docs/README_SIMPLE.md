# PharmaWatch — plain-English setup

This short guide has been folded into the main documents. Use these instead:

- **To install and run it:** follow the Quick start in [`../README.md`](../README.md), or the full
  [`DEPLOYMENT.md`](./DEPLOYMENT.md).
- **To run it for a class:** [`PILOT_GUIDE.md`](./PILOT_GUIDE.md).

In one paragraph: install Docker Desktop, open a terminal in the project folder, and run
`./setup.ps1` (Windows) or `./setup.sh` (macOS/Linux). The script downloads the FDA data, builds
the app and starts it. Then open **http://localhost:5000**. First build takes ~10–15 minutes.

> Research and educational use only. PharmaWatch screens and explains reported drug–event signals;
> it is not a clinical tool and a signal is not proof that a drug caused an event.
