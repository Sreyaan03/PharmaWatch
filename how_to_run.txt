How to Run PharmaWatch

1. Prerequisites
Ensure you have Python 3.10+ installed on your system.

2. Setup the Environment
Open a PowerShell terminal in the PharmaWatch project folder and activate the virtual environment:
.\venv\Scripts\Activate.ps1

3. Install Dependencies
Install the required Python packages by running:
pip install -r backend\requirements.txt

4. API Key Setup
Ensure you have an FDA API key. There should be a `.env` file inside the `backend\` folder containing:
FDA_API_KEY=your_api_key_here

5. Run the Server
Start the Flask backend server:
python backend\app.py

6. Open the Dashboard
Once the server is running, open your web browser and go to:
http://127.0.0.1:5000
