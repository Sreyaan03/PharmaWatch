              Analytical Methodology

              Multi-tiered analytical approach from statistical baseline to deep learning prediction.

              01
              🤖

              BioBERT Natural Language Processing

              Patient-reported outcomes on social media are processed by a BioBERT model deployed as a Spark UDF. It extracts medical entities from colloquial text, converting them into structured {drug, event, severity} tuples mapped to MedDRA codes.

              Live NLP Throughput
              6,120 entities/min

              🔬 Try BioBERT Live

              02
              📐

              PRR Disproportionality Analysis

              The Proportional Reporting Ratio (PRR) detects statistical anomalies in drug-event pairings relative to background database frequency across rolling temporal windows.

              PRR = a / (a + b)c / (c + d)
              a = target drug + target event
              b = target drug + all other events
              c = all other drugs + target event
              d = all other drugs + all other events
              Signal threshold: PRR > 1.0 with ≥ 3 reports

              Live PRR Calculator

              03
              🕸

              Graph-Theoretic Interaction Analysis

              Drugs are represented as nodes and co-prescriptions as weighted edges in a distributed graph. Community detection algorithms surface polypharmacy sub-clusters that collectively precipitate ADEs — uncovering non-linear risks that pairwise analysis misses.

              Connected Components Community Detection Betweenness Centrality Distributed Graph Mining
              04
              📈

              LSTM Temporal Sequence Modelling

              Long Short-Term Memory (LSTM) networks trained on historical event frequencies predict the expected baseline reporting rate. Real-time deviations from predicted baselines flag accelerating signals before traditional PRR thresholds are breached.

                About PharmaWatch

                A Big Data Mini-Project by Manipal Academy of Higher Education

                Abstract

                Adverse Drug Events (ADEs) represent a significant public health challenge, responsible for millions of emergency room visits annually. Traditional pharmacovigilance relies on manual, latency-heavy reporting systems, allowing harmful drug patterns to persist undetected for months.

                PharmaWatch proposes a near real-time, multi-source signal detection architecture. By leveraging a robust big data stack including Apache Kafka, Apache Spark, and distributed Hadoop storage, alongside advanced machine learning models (BioBERT, LSTMs, and Graph-theoretic models), this system ingests heterogeneous data streams to identify and alert stakeholders to emerging ADEs before they reach statistical severity.
