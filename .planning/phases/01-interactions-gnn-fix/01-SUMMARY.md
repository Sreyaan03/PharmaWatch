## What Was Built

### Plan 01 — GNN Training Pipeline Fix
- `DDIDataset` now generates 25 000 positive + up to 25 000 negative pairs (50/50 balanced)
- Negative pairs generated by shuffling the SMILES pool and excluding known positives via frozenset lookup
- Atom feature vector extended from 8 → 16 dimensions (added: H-count, aromaticity, ring membership, stereo centre, P/Br/I one-hots, hybridization)
- `GNN_Predictor` updated to `node_feature_dim=16`
- Training raised to 20 epochs with 80/20 train/val split and best-model checkpointing on val_accuracy
- `backend/app.py` `_load_gnn()` updated to `node_feature_dim=16`

### Plan 02 — Side-effects on Graph + Safe-graph Fix
- `polypharmacy_analysis` endpoint adds HBase side-effect lookup per harmful pair (graceful fallback if HBase offline)
- `side_effects` field propagated through pairs → links → D3 graph
- `normalizePolyGraph` passes `side_effects` from pairs map into each link
- Edge tooltip now shows side-effect text in italic blue when available
- `renderPolyPairs` adds `.poly-pair-item__se` div below each pair card
- Graph early-return removed: always renders drug nodes; shows "✓ No harmful interactions" SVG caption when all pairs safe

### Plan 03 — Graph UX Polish
- D3 zoom/pan added with `d3.zoom().scaleExtent([0.4, 3])`; all graph content in zoom-wrapper `<g>`
- "⟳ Reset zoom" button added top-right of graph container
- Drug label truncation raised from 12 → 18 chars; font bumped to 11px bold, dy=38
- PubChem resolution in `polypharmacy_analysis` converted from serial loop to `ThreadPoolExecutor(max_workers=5)`; expected to cut 5-drug wait from ~25s to ~5s
- `.poly-pair-item__se` CSS added to `style.css`
