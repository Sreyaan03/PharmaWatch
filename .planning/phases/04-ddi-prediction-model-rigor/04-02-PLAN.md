<objective>
Implement a modern, expressive graph neural network architecture for drug pair representation learning. Upgrade from GINConv to GINEConv with edge feature integration (bond types, conjugation, ring status, stereo). Add multi-pooling (mean + max + sum), an auxiliary toggleable Morgan fingerprint branch (ECFP4 2048-bit), and a mathematically symmetric pair interaction head $[a+b, a \odot b, |a-b|]$ guaranteeing $f(A, B) \equiv f(B, A)$. Implement batch-level drug embedding deduplication for optimal throughput.

Purpose: Guarantee permutation-symmetric interaction predictions and richer chem-structural representation.
Output: `scripts/models_ddi.py`, `tests/test_ddi_model.py`.
</objective>

  <files>scripts/models_ddi.py</files>

In `scripts/models_ddi.py`, implement `GINE_DrugEncoder(node_in_dim=22, edge_in_dim=10, hidden_dim=128, num_layers=4, dropout=0.1)`:
1. Linear edge projection mapping `edge_in_dim` to `hidden_dim`.
2. Initial node projection: `Linear(node_in_dim, hidden_dim)` + `BatchNorm1d` + `ReLU`.
3. 3-4 layers of `GINEConv`:
   - Message passing MLP: `Linear(hidden_dim, hidden_dim) -> BatchNorm1d -> ReLU -> Linear(hidden_dim, hidden_dim)`.
   - Residual connection: $x^{(l)} = x^{(l-1)} + \text{conv}(x^{(l-1)}, \text{edge\_index}, \text{edge\_attr})$.
   - Regularization: `BatchNorm1d` + `ReLU` + `Dropout(0.1)` after each layer.
4. Readout pooling:
   - Compute `mean_pool = global_mean_pool(x, batch)`.
   - Compute `max_pool = global_max_pool(x, batch)`.
   - Compute `sum_pool = global_add_pool(x, batch)`.
   - Concatenate all 3: `torch.cat([mean_pool, max_pool, sum_pool], dim=-1)` ($384$-d).
   - Linear projection: `Linear(384, 256) -> BatchNorm1d -> ReLU -> Dropout(0.1)`.
5. Auxiliary Morgan Fingerprint branch:
   - `fp_mlp = nn.Sequential(nn.Linear(2048, 256), nn.BatchNorm1d(256), nn.ReLU(), nn.Dropout(0.1), nn.Linear(256, 128))`.
   - When `use_fingerprint=True`, concatenate: `torch.cat([graph_emb, fp_emb], dim=-1)` ($384$-d).
   - When `use_fingerprint=False`, use the 256-d graph embedding directly.
  </action>

  <action>
In `scripts/models_ddi.py`, implement `SymmetricPairHead` and complete model `GINEDDIPredictor`:
1. `SymmetricPairHead(drug_dim, hidden_dim=256, dropout=0.2)`:
   - Takes drug embeddings $a$ and $b$ (both `[B, drug_dim]`).
   - Computes:
     - $s_{sum} = a + b$
     - $s_{prod} = a * b$
     - $s_{diff} = |a - b|$
   - Concatenates: $h = [s_{sum}, s_{prod}, s_{diff}]$ of dimension `3 * drug_dim`.
   - Projects: `Linear(3 * drug_dim, 256) -> LayerNorm(256) -> ReLU -> Dropout(0.2) -> Linear(256, 1)`.
   - Returns raw logit.
2. In `GINEDDIPredictor.forward_pairs(unique_graphs, unique_fps, pair_indices)`:
   - Evaluates encoder on unique molecules in the batch once.
   - Indices into pair matrix using `pair_indices[:, 0]` and `pair_indices[:, 1]`.
   - Passes symmetric pairs through `SymmetricPairHead`.
3. Provide single-pair inference wrapper `predict_pair(smiles_a, smiles_b)`.
  </action>
