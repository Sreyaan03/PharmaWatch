Build a scientifically honest dataset pipeline for Drug-Drug Interaction (DDI) prediction based on TDC DrugBank (~1,706 approved drugs). Eliminate pair-level split leakage by implementing drug-level splits (75% train, 10% val, 15% test). Generate S0 (warm), S1 (one unseen), and S2 (both unseen) evaluation sets. Add hard code assertions and unit tests verifying zero drug leakage and robust SMILES parsing.

Purpose: Provide disjoint, non-leaking, reproducible splits essential for evaluating inductive generalizability.
Output: `scripts/curate_ddi_dataset.py`, `data/splits/`, `tests/test_ddi_dataset.py`.
</objective>

<task type="auto">
  <name>Task 2: Implement Drug-Level S0, S1, S2 Split Generator with Leakage Assertions</name>
  <files>scripts/curate_ddi_dataset.py, data/splits/train_pairs.csv, data/splits/val_pairs.csv, data/splits/test_s0_pairs.csv, data/splits/test_s1_pairs.csv, data/splits/test_s2_pairs.csv</files>
  <read_first>.planning/phases/04-ddi-prediction-model-rigor/RESEARCH.md</read_first>
  <action>
In `scripts/curate_ddi_dataset.py`, implement `generate_drug_level_splits(drugs, pos_pairs, test_ratio=0.15, val_ratio=0.10, seed=42)`:
1. Partition unique drug IDs randomly using `seed=42`:
   - 75% `train_drugs`
   - 10% `val_drugs`
   - 15% `test_drugs`
2. Enforce strict disjointness:
   - `assert len(train_drugs.intersection(val_drugs)) == 0`
   - `assert len(train_drugs.intersection(test_drugs)) == 0`
   - `assert len(val_drugs.intersection(test_drugs)) == 0`
3. Partition positive interaction pairs:
   - **Train Pairs**: Pairs where *both* drugs are in `train_drugs`.
     Add hard assertions:
     `assert all(d1 in train_drugs and d2 in train_drugs for d1, d2 in train_pairs)`
     `assert not any(d1 in val_drugs or d1 in test_drugs or d2 in val_drugs or d2 in test_drugs for d1, d2 in train_pairs)`
   - **Val Set (S1-style)**: Pairs where exactly one drug is in `train_drugs` and one is in `val_drugs`.
   - **S0 Test Set (Warm)**: Hold out 20% of pairs between `train_drugs` from training to evaluate warm-start generalization.
   - **S1 Test Set (One Unseen)**: Pairs where exactly one drug is in `train_drugs` and one is in `test_drugs`.
   - **S2 Test Set (Fully Cold)**: Pairs where *both* drugs are in `test_drugs`.
4. Negative pair generation for evaluation sets (S0, S1, S2, Val):
   - Sample candidate pairs from the corresponding drug sets that are NOT in the positive interaction set at 1:1 ratio.
5. Save splits as reproducible CSV artifacts in `data/splits/`.
  </action>
  <verify>venv\Scripts\python.exe scripts/curate_ddi_dataset.py --generate-splits</verify>
  <acceptance_criteria>
