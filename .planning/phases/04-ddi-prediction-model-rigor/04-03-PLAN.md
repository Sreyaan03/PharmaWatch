<objective>
Build a robust, scientifically honest training engine for the GINE DDI model. Eliminate artificial soft targets by using standard BCEWithLogitsLoss on hard 0/1 labels with 1:1 negatives resampled fresh each epoch from unlabeled pairs. Execute multi-seed training (5 seeds) reporting mean ± std, with early stopping governed by S1 validation AUPRC. Post-hoc calibrate the model using temperature scaling on validation data, compute Expected Calibration Error (ECE), and generate a reliability diagram. Save the production checkpoint as `drugbank_gine_model.pth`.

Purpose: Provide robust model weights and calibrated probability estimates labeled as interaction likelihood score.
Output: `scripts/train_gnn_model.py`, `scripts/calibrate_model.py`, `backend/trained_models/drugbank_gine_model.pth`, `reports/ddi_calibration_reliability_diagram.png`.
</objective>

  <files>scripts/train_gnn_model.py</files>
  <read_first>scripts/models_ddi.py, data/splits/train_pairs.csv, data/splits/val_pairs.csv</read_first>
  <action>
In `scripts/train_gnn_model.py`, rewrite the training loop:
1. **Dynamic Negative Sampler**:
   - Positives loaded from `data/splits/train_pairs.csv` (labeled 1.0).
   - In each training epoch, draw equal number of negative pairs (labeled 0.0) uniformly from candidate pairs in `train_drugs` that are NOT documented positives.
   - Resample fresh negatives every epoch.
2. **Loss and Optimization**:
   - `criterion = nn.BCEWithLogitsLoss()` on hard 0/1 targets (no soft targets).
   - Optimizer: `AdamW(model.parameters(), lr=1e-3, weight_decay=1e-5)`.
   - Cosine learning rate schedule: `CosineAnnealingLR(optimizer, T_max=epochs, eta_min=1e-6)`.
   - Batch size: 512 pairs.
3. **Validation & Checkpointing**:
   - Evaluate after each epoch on `val_pairs.csv` (the S1-style cold-start validation set).
   - Compute validation AUPRC and AUROC.
   - Save best model checkpoint when validation AUPRC improves (early stopping patience = 5).
4. **Checkpoint Location and Naming**:
   - Save to `backend/trained_models/drugbank_gine_model.pth`.
   - Save metadata dict containing model state, hyperparameters, and best validation metrics.
  </action>
