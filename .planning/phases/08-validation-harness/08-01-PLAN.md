<task type="auto">

  <files>backend/validation/signals_benchmark.py, backend/validation/metrics.py, backend/tests/test_signals_benchmark.py</files>
  <read_first>backend/faers/stats.py, backend/validation/ddi_eval.py</read_first>
  <action>
1. For each reference pair, compute the 2×2 table over the union of the outcome's Preferred Terms, then PRR, lower ROR bound and IC025.
2. `metrics.py`: AUC, sensitivity and specificity at the app's own thresholds, precision at k, and bootstrap intervals; shared with the DDI and NER benchmarks.
3. Report coverage (pairs with at least three cases) and score both "covered pairs only" and "all pairs, uncovered counted as no signal".
4. Report each of the three scores separately, and the app's class rule as a single operating point.
5. Write `reports/validation/signals.json` with metrics, data version, reference checksums and run date.
6. `--smoke` runs a fixed subset against the fixture database for CI.
